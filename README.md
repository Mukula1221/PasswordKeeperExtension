# 密碼小管家

繁體中文 | [English](docs/README.en.md) | [日本語](docs/README.ja.md)

補回被鎖住的「記住密碼」和「自動填入」的瀏覽器擴充功能。Edge 和 Chrome 都能用。

密碼只存在這台電腦的瀏覽器裡，不會上傳到任何地方，擴充功能也不連任何外部伺服器。

## 功能

- 登入後問要不要儲存，下次打開登入頁自動填好。
- 兩段式登入（先打帳號、下一頁才打密碼）和瀏覽器自己跳的帳密視窗都能處理。
- 產生強密碼，字數和要用哪些字元都可以設。
- 自動點選：帳密填好後自動按你選的按鈕，例如單一登入按鈕。
- 工具鎖定：離開座位時鎖起來，用 Windows Hello、Touch ID 或安全金鑰解鎖。
- 加密備份、自動備份，也可以用 CSV 和 Chrome、Edge、Firefox 互搬密碼。
- 介面支援繁體中文、英文、日文。預設跟著瀏覽器的語言，也可以在管理頁右上角換。

## 下載安裝

1. 到 [Releases](../../releases) 下載最新版的 `password-keeper-版本號.zip`。
2. 解壓縮到一個不會刪掉的資料夾，例如「文件」底下的「密碼小管家」。瀏覽器每次啟動都從這個資料夾讀程式，資料夾刪掉就不能用。
3. 打開擴充功能管理頁：
   - Edge：網址列輸入 `edge://extensions`
   - Chrome：網址列輸入 `chrome://extensions`
4. 打開「開發人員模式」的開關。Edge 在左下角，Chrome 在右上角。
5. 按「載入解壓縮」（Chrome 叫「載入未封裝項目」），選剛剛解壓縮的資料夾，也就是有 `manifest.json` 的那一層。
6. 工具列會出現一個藍色鎖頭圖示。按一下工具列的拼圖圖示，可以把鎖頭釘選出來。

安裝前就開著的分頁要重新整理一次，擴充功能才會在那些分頁生效。

Edge 和 Chrome 不讓商店以外的 `.crx` 安裝檔直接安裝，所以要解壓縮後用「載入解壓縮」。

想確認下載的檔案沒被改過，可以在 PowerShell 算一次雜湊值，跟 Release 頁面上同名的 `.sha256` 比對：

```powershell
Get-FileHash password-keeper-1.13.0.zip
```

## 更新到新版

1. 先到管理頁「備份」分頁按「匯出加密備份」，以防萬一。
2. 下載新版的 zip，解壓縮。可以蓋掉原本的資料夾，也可以放到新的資料夾。
3. 蓋掉原本的資料夾的話，在擴充功能管理頁按密碼小管家卡片上的「重新載入」。放到新的資料夾的話，按「載入解壓縮」選新的資料夾，確認新版能用之後再刪掉舊的資料夾。
4. 開著的分頁重新整理一次。

從 Releases 下載的正式版，擴充功能 ID 固定是 `fgmjnolhbeohanamhnomcpmolhdapdkg`。換資料夾裝新版也是同一個擴充功能，存的密碼、設定和工具鎖定都會留著。新版多了權限時，瀏覽器會問一次。

直接載入原始碼資料夾的是開發版。開發版的 ID 跟資料夾位置綁在一起，跟正式版是兩個不同的擴充功能，資料不互通。開發版要換成正式版時，先從開發版匯出加密備份，裝好正式版之後匯入，工具鎖定要重新啟用。開發版和正式版不要同時開著，不然兩個都會自動填入。

## 怎麼用

- **儲存**：到任何網站登入一次，畫面右上角會跳「要儲存這組密碼嗎？」。按「儲存」就存起來。按「這個網站永遠不問」之後，這個網站就不會再跳提示。
- **自動填入**：下次再開同一個網站的登入頁，帳號密碼會自動填好。每個網站可以分開關掉，在管理頁「設定」分頁的「各網站」表，或小視窗「這個網站」底下的「自動填入」。「打開登入頁時自動填入帳號密碼」是總開關，關掉時所有網站都不自動填。
- **選帳號**：同一個網站存了好幾組帳號時，點帳號或密碼欄位會跳清單讓你選。上下鍵選、Enter 填、Esc 關。欄位有焦點時按下鍵也會打開清單。
- **快捷鍵**：按 `Ctrl+Shift+L`，目前網站最近用過的那組帳密直接填進去。要改快捷鍵，到 `edge://extensions/shortcuts`（Chrome 是 `chrome://extensions/shortcuts`）。
- **產生強密碼**：註冊或改密碼時，點新密碼欄，清單最上面有「產生強密碼」，按下去新密碼和確認欄一起填好，也會複製到剪貼簿。送出後照常問你要不要儲存。字數範圍和要用哪些字元，在工具列小視窗的「產生密碼」裡設定。
- **工具列圖示**：點鎖頭可以看目前網站存的帳號、手動填入、複製密碼、新增帳號、產生密碼。圖示上的數字是目前網站有幾組帳號。
- **管理頁**：點鎖頭再點「管理所有密碼」，可以搜尋、修改、刪除、備份、關掉自動填入。備份和設定分頁的每個區塊，點標題可以收合。
- **介面語言**：管理頁右上角地球圖示旁邊的選單，可以選跟著瀏覽器、繁體中文、English、日本語。選了之後管理頁馬上換，小視窗和解鎖視窗下次打開就是新語言，開著的網頁上的提示也會換。擴充功能管理頁上的名稱和說明、快捷鍵的說明、工具列圖示的提示文字是瀏覽器顯示的，還是跟著瀏覽器的語言。
- **舊密碼**：改過密碼的帳號，管理頁的密碼欄會有「舊密碼」可以展開，最多留 5 個。網站那邊其實沒改成功的時候，可以從這裡拿回舊的。
- **回收桶**：刪掉的帳號先進回收桶，「刪除全部密碼」也一樣。預設放 30 天，期間可以復原，之後自動清掉。天數在回收桶分頁改，範圍 1～365 天。可以勾選多筆一起還原或永久刪除。
- **密碼健檢**：管理頁列出「好幾個網站共用同一組密碼」「太短或只有一種字元」「超過一年沒改」，每一筆可以直接修改。
- **挑幾筆給同事**：管理頁表格勾選要給的帳號，按「匯出勾選的（加密）」，設一組密碼。同事用「匯入加密備份」收，密碼另外告訴對方。
- **登入捷徑**：小視窗最上面的搜尋框打網站或帳號的一部分，列出所有符合的帳號。按「開啟」或 Enter 會開新分頁到那個網站，頁面載好就自動填這一組。
- **自動登入**：在管理頁「設定」分頁的「各網站」表勾「自動填完按登入」，或在小視窗「這個網站」底下勾「自動填完就按登入」。之後開那個網站的登入頁，自動填好就幫你按登入。只在自動填入成功、而且頁面上只有一個登入表單時才會按，從清單手動選帳號不會按。
- **自動點選**：帳密填好還要自己按按鈕，或頁面只有一顆單一登入按鈕時用。開到那一頁，按小視窗的「選要自動點的按鈕」，在網頁上點那顆按鈕（這時只會選取，不會真的按到），再選「自動填完才點」或「頁面一打開就點」。之後開到那一頁就會自動點。同一頁可以選好幾顆，前一條點完才輪下一條。規則在管理頁「設定」分頁的「自動點選」區塊，按網站分開，每個網站可以收合。每條可以用 ▲▼ 調整順序，也可以開關、刪除，或改按鈕文字、網址、選擇器、什麼時候點、間隔、等不到按鈕時怎麼辦。網址預設只對選的那一頁生效，`*` 代表任意字元，整個網站填 `*`。改選擇器會清空按鈕文字，留空就只看選擇器。
- **手動新增自動點選**：管理頁「設定」分頁的「自動點選」區塊按「＋ 新增」，填網站、網址和選擇器。「各網站」旁邊的按鈕用來加新網站，每個網站區塊裡的按鈕會先填好網站，新規則排在那個網站的最後。「網站」可以貼整個網址，會自動拆成網站和網址，查詢字串不留。相同網站、網址、選擇器的規則已經存在時不能再新增。
- **瀏覽器的「需要驗證」小視窗**：Jenkins、網路設備那種瀏覽器自己跳的帳密視窗，只要那個網站在這裡有存帳號，會直接回答，視窗不會跳出來。帳密不對的話第二次就讓視窗照常跳。在那個視窗裡手打的帳密存不進來，要先用小視窗「新增帳號」存。
- **工具鎖定**：整個工具的鎖。管理頁「設定」分頁打開「工具鎖定」，會跳一次系統驗證建鑰匙（Windows 是 Windows Hello，Mac 是 Touch ID，沒有內建驗證器的系統用安全金鑰或手機）。鎖上之後，小視窗、管理頁、網頁自動填入、快捷鍵、瀏覽器驗證視窗都要先驗證才能用。什麼時候會鎖上：沒碰電腦 N 分鐘、Windows 進鎖定畫面、瀏覽器重開（可以關）、按小視窗右上角的「鎖定」。管理頁每次打開都要驗證。從小視窗驗證會先開一個小獨立視窗，驗過視窗自己關掉。Windows Hello 沒有自動跳出來的話，按視窗裡的「點這裡重新開啟」。停用也要驗證一次。沒有備用的 PIN。

## 備份

密碼只有瀏覽器裡這一份。移除擴充功能、或清除瀏覽資料時勾到擴充功能資料，密碼就會不見，所以要定期備份。

- **加密備份（建議用這個）**：管理頁按「匯出加密備份」，設一組備份密碼，跳「另存新檔」讓你選位置，存成 `.pkbak` 檔。沒有這組密碼打不開這個檔，密碼忘了也救不回來。「匯入加密備份」選檔案、輸入密碼就還原，已經有的帳號會合併，不會重複。
- **自動備份**：管理頁「備份」區塊裡打開。先設一組自動備份密碼（存在擴充功能裡，跟平常那份的保護等級一樣），選每天或每週、幾點，取一個子資料夾名稱。到時間、而且上次之後有改過密碼，就自動把加密檔存到瀏覽器「下載」資料夾底下的那個子資料夾。錯過時間會在下次開瀏覽器時補做。擴充功能只能寫到「下載」底下，這是瀏覽器的限制。「自動備份」標題旁邊的「立即備份」可以馬上存一份，紀錄裡算手動。
- **備份紀錄**：每次備份存到哪個完整路徑、幾筆，都記在管理頁的「備份紀錄」表，可以按自動、手動篩選，最多留 100 筆。改過自動備份的子資料夾也會記一筆，之前的檔案還留在舊位置，要清要自己去刪。
- **刪除備份紀錄**：單筆按那一列的「刪除」，多筆先勾選再按「刪除勾選的紀錄」。刪的時候會問要不要連電腦上的備份檔一起刪。刪不到的檔案會列出位置，請自己去刪。
- **CSV**：「匯出 CSV」存成明文的 CSV 檔，欄位和 Chrome、Edge 自己匯出的格式一樣（`name,url,username,password,note`），Chrome、Edge、Firefox 都能直接匯入，要放在安全的地方。超過 3000 筆會分成幾個檔，因為 Chrome、Edge 一次最多收 3000 筆。「匯入 CSV」可以讀這種檔，也可以讀 Chrome、Edge、Firefox、Safari 匯出的密碼檔，用 Excel 存過變成 Big5 的也讀得出來。
- **和瀏覽器互搬**：擴充功能沒辦法直接讀寫瀏覽器內建的密碼，只能靠 CSV 來回搬，不會自動同步。瀏覽器的密碼頁：Chrome `chrome://password-manager/settings`、Edge `edge://settings/passwords`、Firefox `about:logins`，在那裡找「匯出密碼」「匯入密碼」。匯入這邊時同網站同帳號會合併；檔案裡如果是這邊已經換掉的舊密碼，或 Firefox 檔案記的改密碼時間比這邊早，會保留這邊的，所以來回搬不會把新密碼蓋回舊的。檔案裡沒有備註不會清掉這邊的備註。手機 App 的密碼（`android://` 開頭）不匯入。搬完把 CSV 刪掉。
- **提醒**：超過 30 天沒備份、而且這段期間有新增或修改過密碼，工具列小視窗頂端會出現黃色提示。天數在管理頁的「備份」區塊改，填 0 就關掉。

## 要知道的事

- **沒有主密碼。** 為了跟瀏覽器內建的一樣不用輸入密碼，密碼存在瀏覽器設定檔裡，只有一層簡單的加密，金鑰也在同一個地方。拿到你 Windows 帳號的人就看得到全部密碼，電腦要鎖好。加密備份檔不一樣，那個沒有備份密碼打不開。
- **要開「開發人員模式」才能裝。** 公司如果把開發人員模式也鎖了，就裝不了。Edge 和 Chrome 啟動時可能會跳「停用開發人員模式的擴充功能」的提醒，按「保留」就好。
- **不支援 Firefox。** Firefox 的背景程式寫法不一樣，要另外改。
- **網站是用完整網域區分的。** jira.example.com 和 gitlab.example.com 是兩個網站，帳號不會互相出現。www.example.com 和 example.com 也算兩個。
- **工具鎖定不是加密。** 系統驗證只擋「離開座位時被人翻」，硬碟上資料的保護程度不變。系統驗證綁在擴充功能 ID 上：正式版換資料夾不受影響，開發版換資料夾要重新啟用。系統驗證壞掉（例如公司把 Windows Hello 關掉）就解不開，只能移除擴充功能重裝、再用備份匯入，所以啟用前先匯出加密備份，自動備份也要開著。鎖住的時候自動備份照跑。
- **跨網站的 iframe 不會自動填。** 別人網站裡框進來的登入頁，為了安全不自動填，但點欄位還是可以選帳號手動填。
- **登入失敗不會問。** 送出登入後如果還停在同一個網址、登入表單也還在，會當作密碼打錯，不跳「要儲存嗎？」。少數網站登入成功後也會回到同一個網址、登入框還留著，這種網站就不會問，可以用小視窗的「新增帳號」手動存。
- **兩段式登入**（先打帳號、下一頁才打密碼，像 Microsoft 的登入頁）有處理，但每個網站做法不同，遇到填不進去的網站用工具列的「填入」或「複製密碼」。
- **自動點選什麼時候不點**：工具鎖定鎖著、這個分頁在間隔內點過同一條、這個分頁按過登出還在暫停時間內、輪到這條後 15 秒內等不到按鈕、按鈕文字跟當初選的不一樣。「自動填完才點」還要帳密填好，而且表單裡沒有空欄位（有驗證碼的頁面不會點，選填的空欄位也算）。
- **自動點選的時間**：「時間設定」有間隔預設值和登出後暫停，預設都是 300 秒，登出後暫停填 0 就不暫停。每條規則可以填自己的間隔，留空就用預設值。「自動填完按登入」也用間隔預設值。間隔只決定多久後可以再點，要重新開頁面或跳頁才會再點。可能打錯密碼的網站，間隔不要設太短，帳號可能被鎖。
- **自動點選的順序**：每條最多等 15 秒。等不到按鈕時，選「跳過，換下一條」就輪下一條，選「停止，後面都不點」就不點後面的，換頁才重新開始。「自動填完才點」要等帳密填好才開始排隊，頁面沒有登入表單時不會擋後面的。網頁裡的 iframe 自己算自己的順序，不會跟外層互等。
- **自動點選做不到的**：網站檢查點擊是不是真人按的，或按了才開新視窗的按鈕，自動點會沒反應或被瀏覽器擋掉。網頁元件包起來的按鈕（Shadow DOM）選不到。別人網站框進來的 iframe 不會點。

## 開發

開發環境、專案結構、測試和發布新版的步驟寫在 [CONTRIBUTING.md](CONTRIBUTING.md)。每一版改了什麼看 [CHANGELOG.md](CHANGELOG.md)，管理頁的「版本」分頁也看得到。
