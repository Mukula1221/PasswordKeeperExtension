# パスワードキーパー

[繁體中文](../README.md) | [English](README.en.md) | 日本語

ブラウザーのパスワード管理（パスワードの保存と自動入力）が使えなくされている環境で、その代わりになる拡張機能です。Edge と Chrome で使えます。

パスワードはこのパソコンのブラウザーにだけ保存され、どこにもアップロードされません。拡張機能が外部のサーバーに接続することもありません。

## 機能

- ログインしたあとにパスワードを保存するか確認し、次にログインページを開いたときに自動入力します。
- 2 段階のログイン（ユーザー名を入力したあと、次のページでパスワードを入力する形式）や、ブラウザー自身が表示するログイン画面にも対応します。
- 強力なパスワードを生成します。文字数と使う文字の種類を設定できます。
- 自動クリック：ユーザー名とパスワードを入力したあと、選んでおいたボタン（シングルサインオンのボタンなど）を自動でクリックします。
- アプリロック：席を離れるときにロックし、Windows Hello、Touch ID、セキュリティキーで解除します。
- 暗号化バックアップと自動バックアップ。CSV で Chrome、Edge、Firefox とパスワードをやり取りすることもできます。
- 画面は繁体字中国語・英語・日本語に対応しています。既定ではブラウザーの言語に合わせて表示され、管理ページの右上で切り替えることもできます。

## インストール

1. [Releases](../../../releases) から最新の `password-keeper-<バージョン>.zip` をダウンロードします。
2. 削除しないフォルダー（「ドキュメント」の下の「パスワードキーパー」など）に展開します。ブラウザーは起動するたびにこのフォルダーから拡張機能を読み込むため、フォルダーを削除すると使えなくなります。
3. 拡張機能のページを開きます。
   - Edge：アドレスバーに `edge://extensions` と入力
   - Chrome：アドレスバーに `chrome://extensions` と入力
4. 「開発者モード」をオンにします。Edge は左下、Chrome は右上にあります。
5. 「展開して読み込み」（Chrome では「パッケージ化されていない拡張機能を読み込む」）をクリックし、展開したフォルダー（`manifest.json` があるフォルダー）を選びます。
6. ツールバーに青い鍵のアイコンが表示されます。ツールバーのパズルのアイコンから、鍵のアイコンをピン留めできます。

インストール前から開いていたタブは、一度再読み込みすると拡張機能が使えるようになります。

Edge と Chrome では、ストア以外の `.crx` ファイルを直接インストールできません。そのため zip を展開して読み込みます。

ダウンロードしたファイルが変更されていないか確かめるには、PowerShell でハッシュ値を計算し、Releases ページにある同じ名前の `.sha256` と比べます。

```powershell
Get-FileHash password-keeper-1.13.0.zip
```

## 更新

1. 念のため、管理ページの「バックアップ」タブで暗号化バックアップをエクスポートしておきます。
2. 新しいバージョンの zip をダウンロードして展開します。元のフォルダーに上書きしても、新しいフォルダーに展開してもかまいません。
3. 元のフォルダーに上書きした場合は、拡張機能のページでパスワードキーパーの「再読み込み」をクリックします。新しいフォルダーに展開した場合は、拡張機能の読み込みで新しいフォルダーを選び、新しいバージョンが動くのを確認してから古いフォルダーを削除します。
4. 開いているタブを一度再読み込みします。

Releases からダウンロードしたリリース版の拡張機能 ID は、常に `fgmjnolhbeohanamhnomcpmolhdapdkg` です。別のフォルダーに新しいバージョンを入れても同じ拡張機能として扱われ、保存したパスワード、設定、アプリロックはそのまま残ります。新しいバージョンで権限が増えたときは、ブラウザーが一度確認します。

ソースのフォルダーを直接読み込んだものは開発版です。開発版の ID はフォルダーの場所で決まるため、リリース版とは別の拡張機能になり、データは共有されません。開発版からリリース版に切り替えるときは、開発版で暗号化バックアップをエクスポートし、リリース版をインストールしてからインポートし、アプリロックをもう一度オンにしてください。開発版とリリース版を同時に有効にしないでください。両方が自動入力してしまいます。

## 使い方

- **保存**：どのサイトでも一度ログインすると、画面の右上にパスワードを保存するか確認が表示されます。「保存」をクリックすると保存されます。「このサイトでは確認しない」をクリックすると、そのサイトでは表示されなくなります。
- **自動入力**：同じサイトのログインページを次に開くと、ユーザー名とパスワードが自動入力されます。管理ページの「設定」タブにある「サイト別設定」の表か、ポップアップの「このサイト」にある「自動入力」で、サイトごとにオフにできます。「設定」タブの自動入力のスイッチは全体のスイッチで、オフにするとどのサイトでも自動入力されません。
- **アカウントを選ぶ**：同じサイトに複数のアカウントを保存している場合、ユーザー名かパスワードの欄をクリックすると一覧が表示されます。上下キーで選び、Enter で入力、Esc で閉じます。欄にフォーカスがあるときに下キーを押しても一覧が開きます。
- **ショートカット**：`Ctrl+Shift+L` を押すと、現在のサイトで最後に使ったアカウントが入力されます。ショートカットは `edge://extensions/shortcuts`（Chrome は `chrome://extensions/shortcuts`）で変更できます。
- **強力なパスワードを生成**：登録やパスワード変更のときに新しいパスワードの欄をクリックすると、一覧の一番上に「強力なパスワードを生成」があります。クリックすると新しいパスワードと確認用の欄の両方に入力され、クリップボードにもコピーされます。送信すると、いつもどおり保存するか確認されます。文字数の範囲と使う文字の種類は、ツールバーのポップアップの「パスワードを生成」で設定します。
- **ツールバーのアイコン**：鍵のアイコンをクリックすると、現在のサイトに保存したアカウントの確認、入力、パスワードのコピー、アカウントの追加、パスワードの生成ができます。アイコンの数字は、現在のサイトのアカウント数です。
- **管理ページ**：鍵のアイコンから「すべてのパスワードを管理」をクリックすると、検索、編集、削除、バックアップ、自動入力のオフができます。「バックアップ」と「設定」タブの各セクションは、タイトルをクリックすると折りたためます。
- **表示言語**：管理ページ右上の地球のアイコンの横にあるメニューで、ブラウザーに合わせる、繁體中文、English、日本語から選べます。管理ページはすぐに切り替わり、ポップアップとロック解除ウィンドウは次に開いたときから新しい言語になります。開いている Web ページ上の表示も切り替わります。拡張機能ページの名前と説明、ショートカットの説明、ツールバーのアイコンのツールチップはブラウザーが表示しているため、ブラウザーの言語のままです。
- **以前のパスワード**：パスワードを変更したアカウントは、管理ページのパスワード欄で「以前のパスワード」を展開できます。最大 5 件まで残ります。サイト側で変更が反映されていなかったときは、ここから元のパスワードを取り出せます。
- **ごみ箱**：削除したアカウントは、「すべてのパスワードを削除」も含めてまずごみ箱に入ります。既定では 30 日間保存され、その間は復元でき、過ぎると自動で削除されます。日数は「ごみ箱」タブで 1～365 日の範囲で変更できます。複数を選んで、まとめて復元したり完全に削除したりできます。
- **パスワード診断**：管理ページに、複数のサイトで同じパスワードを使っているもの、短すぎるか 1 種類の文字しか使っていないもの、1 年以上変更していないものが一覧表示されます。それぞれその場で変更できます。
- **同僚に一部を渡す**：管理ページの表で渡したいアカウントを選び、選んだものを暗号化してエクスポートし、パスワードを設定します。同僚は「暗号化バックアップをインポート」で受け取ります。パスワードは別の方法で伝えてください。
- **ログインのショートカット**：ポップアップの一番上の検索ボックスにサイトやユーザー名の一部を入力すると、一致するアカウントがすべて表示されます。「開く」をクリックするか Enter を押すと、新しいタブでそのサイトが開き、ページが読み込まれるとこのアカウントが入力されます。
- **自動ログイン**：管理ページの「設定」タブの「サイト別設定」の表、またはポップアップの「このサイト」で「自動入力後にログイン」をオンにします。以降、そのサイトのログインページを開くと、自動入力のあとにログインボタンをクリックします。自動入力が成功し、ページにログインフォームが 1 つだけある場合にだけクリックします。一覧から手動でアカウントを選んだ場合はクリックしません。
- **自動クリック**：ユーザー名とパスワードを入力したあとに自分でボタンを押す必要があるときや、ページにシングルサインオンのボタンしかないときに使います。そのページを開き、ポップアップの「自動クリックするボタンを選ぶ」をクリックして、ページ上のボタンをクリックします。このときは選ぶだけで、実際にはクリックされません。続けて、自動入力のあとにクリックするか、ページを開いたらすぐにクリックするかを選びます。以降、そのページを開くと自動でクリックされます。同じページで複数のボタンを選ぶこともでき、前のルールが終わってから次のルールに進みます。ルールは管理ページの「設定」タブの「自動クリック」セクションにサイトごとにまとめられ、サイトごとに折りたためます。▲▼ で順番を変えたり、オン・オフ、削除、ボタンの文字、URL、セレクター、クリックするタイミング、間隔、ボタンが見つからないときの動作を変更したりできます。URL は既定では選んだページにだけ適用されます。`*` は任意の文字を表し、サイト全体に適用するときは `*` にします。セレクターを変更するとボタンの文字は空になり、空のときはセレクターだけで判断します。
- **自動クリックを手動で追加**：管理ページの「設定」タブの「自動クリック」セクションで「＋ 追加」をクリックし、サイト、URL、セレクターを入力します。セクションのタイトルの横にあるボタンは新しいサイト用です。各サイトのセクション内にあるボタンはそのサイトが入力済みで、新しいルールはそのサイトの最後に追加されます。サイトの欄に URL 全体を貼り付けると、サイトと URL に自動で分けられ、クエリ文字列は削除されます。同じサイト、URL、セレクターのルールがすでにある場合は追加できません。
- **ブラウザーが表示するログイン画面**：Jenkins やネットワーク機器のように、ブラウザー自身がユーザー名とパスワードを求める画面は、そのサイトのアカウントが保存されていれば自動で応答し、画面は表示されません。ユーザー名かパスワードが違う場合は、2 回目からはいつもどおり画面が表示されます。その画面で手入力したユーザー名とパスワードは保存できないので、先にポップアップの「アカウントを追加」で保存してください。
- **アプリロック**：ツール全体のロックです。管理ページの「設定」タブで「アプリロック」をオンにすると、システム認証で一度認証します（Windows では Windows Hello、Mac では Touch ID、内蔵の認証機能がないシステムではセキュリティキーまたはスマートフォン）。ロック中は、ポップアップ、管理ページ、Web ページでの自動入力、ショートカット、ブラウザーのログイン画面への応答のすべてで、先に認証が必要です。ロックされるのは、パソコンを一定の時間操作しなかったとき、Windows がロック画面になったとき、ブラウザーを再起動したとき（オフにできます）、ポップアップ右上の「ロック」をクリックしたときです。管理ページは開くたびに認証が必要です。ポップアップから認証すると小さな別ウィンドウが開き、認証が終わると自動で閉じます。Windows Hello が自動で表示されないときは、そのウィンドウの「ここをクリックしてもう一度開く」をクリックしてください。オフにするときも認証が必要です。予備の PIN はありません。

## バックアップ

パスワードはこのブラウザーにしかありません。拡張機能を削除したり、閲覧データの削除で拡張機能のデータも消したりすると、パスワードはなくなります。定期的にバックアップしてください。

- **暗号化バックアップ（おすすめ）**：管理ページの「暗号化バックアップをエクスポート」をクリックし、バックアップ用パスワードを設定して保存先を選びます。`.pkbak` ファイルとして保存されます。このパスワードがないとファイルは開けず、忘れると復元できません。「暗号化バックアップをインポート」でファイルを選んでパスワードを入力すると復元されます。既存のアカウントは重複せずにまとめられます。
- **自動バックアップ**：管理ページの「バックアップ」セクションでオンにします。先に自動バックアップ用のパスワード（拡張機能内に保存され、ほかのデータと同じ保護レベル）を設定し、毎日か毎週か、時刻、サブフォルダー名を選びます。その時刻に、前回からパスワードの変更があれば、ブラウザーの「ダウンロード」フォルダーの下にあるそのサブフォルダーに暗号化ファイルが保存されます。時刻を過ぎていた場合は、次にブラウザーを開いたときに実行されます。拡張機能が書き込めるのは「ダウンロード」の下だけです（ブラウザーの制限）。「自動バックアップ」のタイトルの横にある「今すぐバックアップ」で、すぐに保存することもできます。履歴では手動として記録されます。
- **バックアップ履歴**：バックアップのたびに、保存先のフルパスと件数が管理ページの「バックアップ履歴」の表に記録されます。自動・手動で絞り込むことができ、最大 100 件まで残ります。自動バックアップのサブフォルダーを変更したときも記録されます。以前のファイルは元の場所に残るので、不要なら自分で削除してください。
- **バックアップ履歴の削除**：1 件ならその行の「削除」を、複数なら選んでからまとめて削除します。パソコン上のバックアップファイルも一緒に削除するか確認されます。削除できなかったファイルは場所が表示されるので、自分で削除してください。
- **CSV**：CSV のエクスポートは、暗号化されていない CSV ファイルとして保存します。列は Chrome や Edge が出力する形式と同じ（`name,url,username,password,note`）で、Chrome、Edge、Firefox でそのままインポートできます。安全な場所に保管してください。3000 件を超えると複数のファイルに分かれます（Chrome と Edge は一度に 3000 件までしか読み込めないため）。CSV のインポートはこの形式のほか、Chrome、Edge、Firefox、Safari が出力したパスワードファイルや、Excel で保存して Big5 になったファイルも読み込めます。
- **ブラウザーとのやり取り**：拡張機能はブラウザー内蔵のパスワードを直接読み書きできないため、CSV で移すしかなく、自動では同期されません。ブラウザーのパスワードページは Chrome が `chrome://password-manager/settings`、Edge が `edge://settings/passwords`、Firefox が `about:logins` で、そこでエクスポートとインポートを探してください。こちらにインポートすると、同じサイトで同じユーザー名のアカウントはまとめられます。ファイルのパスワードがこちらで変更済みの古いものだったり、Firefox のファイルに記録された変更日時がこちらより古かったりする場合は、こちらのものが残ります。そのため、行き来しても新しいパスワードが古いもので上書きされることはありません。ファイルにメモがなくても、こちらのメモは消えません。スマートフォンアプリのパスワード（`android://` で始まるもの）はインポートされません。移し終えたら CSV ファイルは削除してください。
- **リマインダー**：30 日以上バックアップしておらず、その間にパスワードを追加または変更した場合、ツールバーのポップアップの上部に黄色の通知が表示されます。日数は管理ページの「バックアップ」セクションで変更でき、0 にするとオフになります。

## 知っておいてほしいこと

- **マスターパスワードはありません。** ブラウザー内蔵の機能と同じようにパスワードを入力せずに使えるよう、パスワードはブラウザーのプロファイルに簡単な暗号化だけで保存され、鍵も同じ場所にあります。Windows のアカウントに入れる人はすべてのパスワードを見られるので、パソコンは必ずロックしてください。暗号化バックアップファイルは別で、バックアップ用パスワードがないと開けません。
- **インストールには「開発者モード」が必要です。** 会社で開発者モードも禁止されている場合はインストールできません。Edge や Chrome の起動時に、開発者モードの拡張機能について警告が表示されることがあります。拡張機能を残す方を選んでください。
- **Firefox には対応していません。** Firefox はバックグラウンドの仕組みが違うため、別途対応が必要です。
- **サイトは完全なドメインで区別されます。** jira.example.com と gitlab.example.com は別のサイトで、アカウントは混ざりません。www.example.com と example.com も別のサイトとして扱われます。
- **アプリロックは暗号化ではありません。** システム認証は席を離れている間にのぞかれるのを防ぐだけで、ディスク上のデータの保護の強さは変わりません。認証は拡張機能 ID に結び付いています。リリース版はフォルダーを変えても影響しませんが、開発版はフォルダーを移すとアプリロックをもう一度オンにする必要があります。システム認証が使えなくなると（会社が Windows Hello を無効にした場合など）ロックを解除できず、拡張機能を削除して再インストールし、バックアップをインポートするしかありません。オンにする前に暗号化バックアップをエクスポートし、自動バックアップもオンにしておいてください。ロック中も自動バックアップは実行されます。
- **別サイトの iframe では自動入力しません。** ほかのサイトに埋め込まれたログインページは、安全のため自動入力しません。欄をクリックしてアカウントを選べば入力できます。
- **ログインに失敗したときは確認しません。** ログインを送信したあとも同じ URL のままで、ログインフォームも残っている場合は、パスワードの入力ミスとみなして保存の確認を表示しません。ログインに成功しても同じ URL に戻ってログイン欄が残るサイトもまれにあります。そのようなサイトでは確認が表示されないので、ポップアップの「アカウントを追加」で手動で保存してください。
- **2 段階のログイン**（ユーザー名のあと、次のページでパスワードを入力する形式。Microsoft のログインページなど）に対応していますが、サイトによってやり方が違います。入力できないサイトでは、ツールバーのポップアップの「入力」か「パスワードをコピー」を使ってください。
- **自動クリックしないとき**：アプリロック中のとき、このタブで間隔内に同じルールをクリック済みのとき、このタブでログアウトをクリックしてから一時停止の時間内のとき、このルールの順番になってから 15 秒以内にボタンが現れないとき、ボタンの文字が選んだときと違うとき。自動入力のあとにクリックするルールは、さらにユーザー名とパスワードが入力済みで、フォームに空の欄がないことが条件です。確認コードのあるページではクリックせず、任意の空欄も空として数えます。
- **自動クリックのタイミング**：タイミングの設定には既定の間隔とログアウト後の一時停止があり、どちらも既定は 300 秒です。一時停止を 0 にすると停止しません。ルールごとに間隔を設定でき、空欄なら既定の間隔を使います。「自動入力後にログイン」も既定の間隔を使います。間隔は次にクリックできるまでの時間を決めるだけで、再びクリックするのはページを開き直すか移動したときです。パスワードを間違える可能性があるサイトでは、アカウントがロックされることがあるので、間隔を短くしすぎないでください。
- **自動クリックの順番**：各ルールは最大 15 秒待ちます。ボタンが現れない場合、スキップに設定したルールは次のルールに進み、停止に設定したルールはそれ以降をクリックしません。ページが変わると最初からやり直します。自動入力のあとにクリックするルールは、ユーザー名とパスワードが入力されてから順番待ちに入り、ログインフォームのないページではあとのルールを止めません。ページ内の iframe はそれぞれ独自の順番で動き、外側のページを待ちません。
- **自動クリックでできないこと**：サイトが人による操作かどうかを確認している場合や、クリックすると新しいウィンドウが開くボタンでは、自動クリックが反応しないか、ブラウザーにブロックされます。Web コンポーネントの中のボタン（Shadow DOM）は選べません。ほかのサイトから埋め込まれた iframe はクリックしません。
