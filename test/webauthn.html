WebAuthn 試驗頁

測試這個擴充功能能不能叫 Windows Hello（Mac 是 Touch ID）來驗證身分。只是試驗，不會動到你存的密碼。

怎麼做

  1. 按「1. 檢查環境」，看這個瀏覽器有沒有內建的驗證器。
  2. 按「2. 建立鑰匙」，應該會跳 Windows 的 PIN 視窗。驗過會看到「鑰匙建立成功」。
  3. 按「3. 驗證」，應該再跳一次 PIN 視窗，驗過會看到「簽章驗證成功」。這就是之後解鎖會走的流程。
  4. 不管成功或失敗，按「複製結果」把下面的紀錄貼給我。
「2b」是給沒有內建驗證器的電腦（例如 Linux）試的，會讓你選實體安全金鑰或手機。
按「1. 檢查環境」開始。
